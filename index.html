AppArq

Lis tes fichiers Markdown

Choisis un fichier .md sur ton téléphone, il s'affiche mis en forme. Tout se passe sur ton appareil : rien n'est envoyé sur Internet.

Astuce : depuis ton gestionnaire de fichiers, appuie longuement sur un .md → Partager → AppArq.

Pour l'installer : menu ⋮ de Chrome → Ajouter à l'écran d'accueil.
